---
name: people-lookup
applies_to: [planner, check]
scope: query
when: "Who someone is, a person's role, team, manager or work; a name or first name"
---
People questions:
- Look the name up in the directory first; it is the source for role, team and manager.
- A first name alone often matches several people. Look it up anyway; never pick one silently.
  Narrow with context from the question or the result that mentioned them (team, project, space),
  and when still ambiguous return every candidate with what distinguishes them.
- Their recent work: tickets by assignee, messages by sender.
